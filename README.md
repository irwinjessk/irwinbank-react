# IrwinBank

Interface React du projet IrwinBank.

## Prérequis

- Node.js 22

## Installation

```bash
npm install
cp .env.example .env
npm run dev
```

L'application tourne sur http://localhost:5173. L'écran d'accueil est la connexion (`/connexion`).

`VITE_API_URL` pointe vers l'API Django locale (`http://localhost:8000`).

## Build

```bash
npm run build
```
